This policy describes the channel owner's publishing application for Korean Between the Lines, operated for the KRstory and NEXT KIDS YouTube channels. Each channel is authorized separately by the owner.

Google data we access

When the owner authorizes the application, it requests YouTube upload and read-only access. The application uses the channel ID and title to confirm the destination, uploads original lesson videos and their metadata, and reads video processing, privacy, and scheduled publication status. Read-only authorization technically permits access to additional YouTube account information; the current application only uses the channel and video information described here.

How data is used and stored

Google OAuth client credentials and refresh tokens are stored in restricted local files on the owner's Mac and DGX Spark 2. They are used to obtain access tokens for authorized YouTube API operations. Channel identifiers, lesson files, and upload/status records are kept in the owner's local episode archive. Tokens, credentials, and private upload session addresses are excluded from this website and its public repository.

Sharing and Limited Use

Videos and metadata are sent to YouTube for uploading and scheduled publication. Google credentials are sent only to Google's authorization endpoints and transferred between the owner's Mac and Spark over SSH. We do not sell Google user data, use it for advertising, or provide it to third-party AI model training services. This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation, and deletion

Authorization credentials are retained until the owner disconnects the application or replaces the authorization. Episode and publication records remain in the owner's archive until deleted. The owner can revoke access through Google Account permissions and request deletion of local authorization data by contacting the operator. Deleting local records or revoking access does not delete an already uploaded video or cancel a scheduled publication on YouTube; the owner manages those separately on YouTube.

Children and viewers

NEXT KIDS videos are intended for elementary-school children. The publishing application is used only by the adult channel owner. This website has no accounts, comment forms, quizzes that submit answers, or requests for children's names, addresses, school details, photos, or Google authorization.

Website visitors

This static website has no sign-in, analytics scripts, embedded third-party media, or application cookies. If hosted on GitHub Pages, GitHub handles hosting request logs, including visitor IP addresses, under the GitHub Privacy Statement. Following a YouTube link takes you to YouTube, where Google's policies apply.

Contact and changes

Questions, deletion requests, and policy updates: viraltest.260628@gmail.com. We update this page when our Google data practices change.
